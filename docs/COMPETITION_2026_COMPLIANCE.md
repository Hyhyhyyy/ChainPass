# 中国国际大学生创新大赛（2026）适配说明

## 结论

ChainPass 可以作为高教主赛道项目准备，但“符合参赛要求”不能由软件或本仓库自行宣称。参赛资格、学籍、年龄、成员实际贡献、知识产权、数据真实性和是否属于往届获奖项目，必须由团队据实举证，并经过学校与后续赛事组织方审核。

按当前产品价值主线，优先建议选择：

- 赛道：高教主赛道；
- 类别：新文科类；
- 方向：金融科技 / 数字经济；
- 组别：必须根据负责人学籍、毕业时间及工商登记状态，在本科生创意组、本科生创业组、研究生创意组、研究生创业组中据实选择。

如果申报材料把核心创新明确收敛到底层区块链、密码工程或网络空间安全，也可论证新工科类，但正式报名只能选择一个赛道与类别，不能同时包装成多个项目重复参赛。

## 产品事实边界

以下内容必须在项目书与答辩中保持一致：

1. CNY、USD、ETH 是内部测试记账单位，不是真实资金或链上资产。
2. 当前系统不连接银行、卡组织、支付机构或区块链结算网络。
3. KYC 是本系统授权审核员的审核结论，不等同于政府或持牌机构认证。
4. `did:chainpass` 是本地标识方法，不是已注册公共 DID method。
5. 凭证格式由项目自定义，只保证本服务内签名与状态验证，不宣称符合 W3C Data Integrity cryptosuite。
6. 合规风险规则是可解释演示策略，不是某一司法辖区的法定阈值、制裁筛查或 AML 认证模型。

## AI 辅助使用诚信

本项目存在 AI 辅助分析、编码、测试和文档整理。团队不得删除或隐瞒这一事实，也不得把无法解释、无法复现的 AI 输出作为个人原创成果申报。正式参赛前，学生团队至少应完成：

1. 逐文件代码审查，能说明入口、调用链、输入输出、失败路径和安全边界；
2. 独立重跑测试与完整业务流程，保留带日期的复现记录；
3. 核实所有事实、数据和引用来源，对错误承担修订责任；
4. 用团队自己的语言重写项目书、PPT 和答辩稿；
5. 按学校和赛事当年规则如实披露 AI 工具的用途与范围。

AI 可以作为开发工具，但不能替代成员的实质性贡献、专业判断和现场答辩能力。

## 新增的自检功能

登录后访问 `/competition/readiness`：

- 固定项目的唯一赛道、类别与组别；
- 对参赛资格、真实性、成员贡献、知识产权、数据材料、学生自主完成和评审纪律逐项确认；
- 未确认的一票否决项会持续显示为阻断项；
- 状态自动保存在本机浏览器，避免额外上传学籍和年龄信息；
- 可导出带时间戳、依据与未完成项的 JSON 记录，供团队和指导教师复核。

导出结果只是内部证据目录，不是学校或赛事组织方的审核证明。
